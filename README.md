# Fullstack App (Vite + React + FastAPI + SQLite)

## Быстрый старт:

1. **Установка зависимостей:**
   ```bash
   npm run install:all
   ```

2. **Запуск в режиме разработки (бэкенд + фронтенд параллельно):**
   ```bash
   npm run dev
   ```

- **Frontend:** http://localhost:5173
- **Backend API Docs:** http://localhost:8000/docs
